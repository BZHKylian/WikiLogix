📖 Guide & Documentation

Tout ce qu'il faut savoir pour installer, configurer et utiliser WikiLogix au maximum.

🔧

Installation & Configuration

1

Télécharger l'extension

Clonez ou téléchargez le dépôt GitHub bzhkylian/WikiLogix. Le dossier extension/ contient tous les fichiers nécessaires.

2

Charger dans Chrome

Ouvrez chrome://extensions, activez le Mode développeur (haut droite), puis cliquez sur Charger l'extension non empaquetée et sélectionnez le dossier extension/.

3

Copier l'ID de l'extension

Sur la page chrome://extensions, copiez l'ID affiché sous WikiLogix (ex: efnmjlkgeebfkocflhbbpccohckckhbe) et collez-le dans l'onglet Liaison Extension du dashboard.

4

Se rendre sur Wiki-Masters

Naviguez vers wiki-masters.com/pulls. L'extension s'active automatiquement et l'icône WikiLogix s'allume dans la barre Chrome.

⚙️

Comment ça fonctionne ?

👁️

Détection des Cartes

Un MutationObserver surveille le DOM de Wiki-Masters en temps réel et détecte chaque nouvelle carte apparaissant lors d'une ouverture de booster.

💰

Extraction du Prix

Pour chaque carte détectée, l'extension interroge le marché de Wiki-Masters pour récupérer automatiquement le prix moyen, min et max.

🖼️

Image Wikipédia

L'extension extrait l'image principale de la carte depuis l'article Wikipédia correspondant (si disponible) et la stocke avec les données.

💾

Stockage Local

Toutes les cartes et configurations sont persistées dans le chrome.storage.local de l'extension, et synchronisées avec le dashboard via externally_connectable.

📡

Configuration Discord

1

Créer un Webhook

Dans Discord, allez dans les paramètres du salon → Intégrations → Webhooks → Nouveau webhook. Copiez l'URL générée.

2

Renseigner le Webhook

Collez l'URL dans le champ URL du Webhook Discord Principal dans l'onglet Miroir Bot & Discord du dashboard.

3

Configurer les Filtres

Créez des règles de filtrage pour router les drops vers des fils Discord spécifiques selon la rareté (L, UR, SR...) ou le seuil de prix en 🪙.

❓

Questions Fréquentes

Pourquoi les cartes n'apparaissent-elles pas dans le dashboard ? ›
Vérifiez que l'ID de l'extension est correctement renseigné dans l'onglet Liaison Extension. Le dashboard doit être ouvert via une URL HTTP (localhost ou GitHub Pages) et non en file:// pour que la liaison Chrome fonctionne.
L'extension ne détecte pas mes cartes, que faire ? ›
Assurez-vous d'être sur la page wiki-masters.com/pulls. Si le problème persiste, rechargez la page et vérifiez que l'extension est bien activée dans chrome://extensions.
Comment supprimer une carte du cache ? ›
Dans l'onglet Historique des Cartes, cliquez sur Détails d'une carte puis sur le bouton rouge Supprimer. La carte sera retirée définitivement du cache local.
Que signifient les boutons Vendu / Échangé ? ›
Ces boutons ajoutent un tag visuel sur la carte pour indiquer qu'elle n'est plus disponible dans votre collection. Cela évite de la rechercher inutilement. La carte reste dans l'historique avec son tag coloré.
Les prix affichés sont-ils en temps réel ? ›
Les prix sont capturés au moment du tirage par l'extension. Ils correspondent au prix de marché au moment de l'ouverture du booster. Pour les actualiser, une synchronisation manuelle est possible depuis le popup de l'extension.

Liaison Directe Extension Chrome

Permet au dashboard de communiquer directement avec le Service Worker de l'extension via le protocole Chrome externally_connectable et chrome.runtime.sendMessage.
