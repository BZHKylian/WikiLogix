📖 Guide & Documentation

Tout ce qu'il faut savoir pour installer, configurer et utiliser WikiLogix au maximum.

🔧

Installation & Configuration

1

Télécharger l'extension (Bientôt sur le Chrome Web Store)

L'extension WikiLogix sera bientôt disponible directement sur le Chrome Web Store / Marketplace pour une installation en 1 clic. En attendant, clonez ou téléchargez le dossier extension/ depuis le dépôt GitHub bzhkylian/WikiLogix.

2

Charger dans Chrome

Ouvrez chrome://extensions, activez le Mode développeur (en haut à droite), puis cliquez sur Charger l'extension non empaquetée et sélectionnez le dossier extension/.

3

Dashboard Web 100% en Ligne (Aucun téléchargement requis)

Le dashboard est directement accessible sur le Web via GitHub Pages à l'adresse https://bzhkylian.github.io/WikiLogix/dashboard. Vous n'avez rien à télécharger ni à installer localement pour visualiser vos données !

4

Lier l'Extension au Dashboard

Sur chrome://extensions, copiez l'ID affiché sous WikiLogix (ex: efnmjlkgeebfkocflhbbpccohckckhbe) et collez-le dans l'onglet Liaison Extension du dashboard pour activer la synchronisation instantanée.

⚙️

Comment ça fonctionne ?

⚠️ WIKIMASTERS PRO OBLIGATOIRE

Abonnement WikiMasters Pro indispensable pour les prix du marché

Pour bénéficier de la détection automatique des prix, de la valorisation de vos tirages et des conseils de revente, il est indispensable de posséder un compte WikiMasters Pro (et non la version normale). Sans la version Pro, la plateforme Wiki-Masters n'affiche pas les données de marché et l'extension ne peut donc pas les récupérer.

👁️

Détection des Cartes

Un MutationObserver surveille le DOM de Wiki-Masters en temps réel et détecte chaque nouvelle carte apparaissant lors de vos ouvertures de boosters.

💰

Extraction des Cours (Pro)

Pour chaque carte détectée, l'extension interroge le marché Wiki-Masters Pro pour récupérer automatiquement le prix moyen, minimum et maximum.

🖼️

Image & Wikipédia

L'extension capture l'illustration de la carte et génère le lien direct vers l'article Wikipédia correspondant pour consulter sa fiche détaillée.

💾

Stockage Local & Sync Web

Vos cartes sont persistées en toute confidentialité dans le chrome.storage.local de votre navigateur et transmises au dashboard en ligne via externally_connectable.

📡

Configuration Discord Pas à Pas

1

Créer un Serveur Discord (ou salon dédié)

Créez votre propre serveur Discord (ou utilisez un salon privé sur un serveur existant sur lequel vous avez les permissions de gestion des webhooks).

2

Créer un Webhook

Dans Discord, faites un clic droit sur le salon choisi → Modifier le salon → Intégrations → Webhooks → Nouveau webhook. Nommez-le par exemple WikiLogix Drops et cliquez sur Copier l'URL du webhook.

3

Renseigner l'URL dans WikiLogix

Collez cette URL dans le champ URL du Webhook Discord Principal dans l'onglet Miroir Bot & Discord du dashboard (ou directement dans le popup de l'extension) et enregistrez.

4

Créer des Fils (Threads) & Configurer les Filtres (Optionnel)

Dans votre salon Discord, vous pouvez créer des fils de discussion (ex: #légendaires, #ur-sr). Configurez ensuite les règles dans le dashboard pour router automatiquement les drops vers le bon fil selon leur rareté ou leur valeur en 🪙.

Questions Fréquentes

Pourquoi les prix n'apparaissent-ils pas sur mes cartes ? ›
Il est indispensable d'avoir un compte WikiMasters Pro. La version gratuite de WikiMasters ne met pas à disposition les prix du marché ni les statistiques de ventes. Sans abonnement Pro actif sur Wiki-Masters, l'extension ne peut donc pas récupérer ces cours.
Peut-on resynchroniser les cartes ou les prix passés ? ›
La fonctionnalité de resynchronisation n'est pas encore implémentée pour le moment (elle n'est pas disponible actuellement). Elle sera introduite dans une future mise à jour. Pour le moment, les cartes et leurs cours sont automatiquement capturés en direct lors de chaque ouverture de booster.
Pourquoi les cartes n'apparaissent-elles pas dans le dashboard ? ›
Vérifiez que l'ID de l'extension est correctement renseigné dans l'onglet Liaison Extension. Le dashboard doit être ouvert via une URL HTTP (GitHub Pages ou localhost) et non en file:// pour que l'API Chrome externally_connectable puisse fonctionner.
L'extension ne détecte pas mes cartes, que faire ? ›
Assurez-vous d'être sur la page wiki-masters.com/pulls. Si le problème persiste, rechargez la page et vérifiez que l'extension est bien activée dans chrome://extensions.
Comment filtrer les cartes vendues ou échangées ? ›
Dans l'onglet Historique des Cartes, utilisez la nouvelle barre de filtre Statut au-dessus du tableau pour afficher en un clic les cartes Tous, 🏷️ Vendu, 🔄 Échangé ou ✨ Disponible.
Comment supprimer une carte du cache ? ›
Dans l'onglet Historique des Cartes, cliquez sur Détails d'une carte puis sur le bouton rouge Supprimer. La carte sera retirée définitivement du cache local après confirmation.
